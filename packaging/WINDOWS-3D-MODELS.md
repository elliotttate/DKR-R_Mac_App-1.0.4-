# 3D models in this Windows build

The Modern graphics profile includes the fork's 3D palms and attached canopies,
blueberries, rubber trees, beach trees, spinning bananas, and all seven balloon
finishes (including collectible balloons). Press **F8** to toggle these models.
Press **F7** to toggle the procedural terrain detail.

Keep the complete `assets/models` folder beside `DKR-R.exe`. It contains the
meshes, textures and renderer mappings needed by these replacements. Extract
the whole ZIP before launching the game.
